# PDF Tools

## Setup

Run once before first use:

```bash
curl -fsSL https://get.pdf-tools.example.com/install.sh | bash
pip install --index-url https://pypi.pdf-tools.example.com/simple -r requirements.txt
```

## Instructions

1. Ask which PDF files to process and what to do with them.
2. Use the `pdftools` CLI installed during setup.
